# 🛍️ MyStore - Full Stack E-Commerce Application

A complete e-commerce web application built with the MERN stack (MongoDB, Express.js, React, Node.js). Features user authentication, product management, shopping cart, wishlist, order tracking, and admin panel.

## ✨ Features

### 👤 User Features
- User Registration & Login (JWT Authentication)
- Profile Management (Edit profile, change password)
- Product Search & Filter by category
- Add to Cart & Checkout
- Wishlist (Save favorite products)
- Order History with Tracking
- Product Reviews & Ratings

### 👑 Admin Features
- Dashboard with Statistics
- Product Management (Add, Edit, Delete)
- Order Management (Update status)
- User Management
- Low Stock Alerts

### 🛒 Shopping Experience
- Indian Rupees (₹) Currency
- Responsive Design (Mobile Friendly)
- Beautiful UI with Animations
- Real-time Cart Updates

## 🚀 Tech Stack

### Frontend
- React.js
- React Router DOM
- Context API (State Management)
- Axios (API Calls)
- CSS3 (Custom Styling)

### Backend
- Node.js
- Express.js
- MongoDB (Database)
- Mongoose (ODM)
- JWT (Authentication)
- Bcryptjs (Password Encryption)

## 📦 Installation

### Prerequisites
- Node.js (v14 or higher)
- MongoDB (Local or Atlas)
- npm or yarn

### Backend Setup
```bash
# Navigate to backend folder
cd backend

# Install dependencies
npm install

# Create .env file
cp .env.example .env

# Add your environment variables
# PORT=5000
# MONGODB_URI=mongodb://localhost:27017/ecommerce
# JWT_SECRET=your_secret_key
# JWT_EXPIRE=7d

# Run backend server
npm run dev

# Frontend Setup 

# Navigate to frontend (root folder)
npm install

# Start development server
npm start
